TruthLens AI 🔍

Verify Before You Share

TruthLens AI is an AI-powered social media misinformation detection project designed to help users identify suspicious news, images, and online content before sharing.

Features

- Social media misinformation awareness
- AI-powered content analysis
- User-friendly interface
- Helps users make informed sharing decisions

Tech Stack

- Python
- Streamlit
- Pillow

Project Purpose

To promote responsible social media usage and help people think critically about online information.

Future Scope

- Fake news detection
- AI-generated image detection
- Scam link detection
- Credibility score
- Trusted source verification
